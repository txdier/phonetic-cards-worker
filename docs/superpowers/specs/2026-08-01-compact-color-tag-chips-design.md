# 紧凑颜色标签胶囊设计

## 背景

现有标签选择胶囊采用 44 像素最小高度，并始终为左侧勾选标记预留
14 像素空间。实际表单中，胶囊因此显得偏高；未选中状态虽然不显示小勾，
文字仍被预留空间推向右侧，视觉上没有居中。

本次设计是对现有标签胶囊的视觉修订，不改变标签创建、加载、选择或提交逻辑。

## 目标

- 所有设备上的标签胶囊统一为 32 像素高度。
- 删除小勾和对应的占位空间，使标签文字真正水平、垂直居中。
- 已选中与未选中状态只通过背景、边框和文字颜色区分。
- 保留原生复选框语义、键盘切换、读屏选中状态和焦点环。
- 添加/编辑单词与待整理收录表单继续共用同一套样式。

## 视觉与交互

### 尺寸与对齐

- `.pc-tag-choice` 的固定最小高度由 44 像素改为 32 像素。
- 使用紧凑的垂直内边距和约 11 像素的水平内边距。
- 胶囊使用 `inline-flex`、`align-items: center` 和
  `justify-content: center`，标签文字在可用区域内居中。
- 删除 `.pc-tag-choice::before` 和已选中状态的伪元素规则，不再保留图标空间。
- 长标签继续保持单行、限制最大宽度并隐藏溢出，避免横向滚动。

### 未选中状态

- 使用现有面板背景 `--bg-panel`。
- 使用普通边框 `--line`。
- 使用次级文字颜色 `--ink-dim`。

### 已选中状态

- 背景使用低强度的 `--teal` 与 `--bg-panel` 混合色。
- 边框使用 `--teal`。
- 文字使用 `--teal` 与 `--ink` 的高对比混合色。
- 不增加图标、圆点、下划线、字样或其它非颜色标记。
- 选中前后不改变内边距、尺寸或字体宽度，避免布局跳动。

### 其它状态

- 悬停与按下反馈继续只对未禁用标签生效。
- 禁用标签保留降低透明度和禁止光标。
- 键盘焦点继续显示现有主题色焦点环。
- 原生复选框继续在视觉上隐藏，但保留在键盘顺序和可访问树中。

## 无障碍取舍

可见的选中状态按用户要求仅通过颜色表达，因此不采用“颜色之外再提供标记”的
视觉建议。为降低影响：

- 原生 `input[type="checkbox"]` 不移除，读屏仍会播报选中状态。
- 键盘用户仍可使用 Tab 聚焦并用空格切换。
- 焦点状态不依赖选中颜色，继续使用独立轮廓。
- 明暗主题中的文字与选中背景需保持至少 4.5:1 对比度。

## 实现边界

- 修改 `public/styles.css` 中 `.pc-tag-choice` 及其状态规则。
- 删除与小勾相关的伪元素样式。
- 不修改 `public/words-view.js`、`public/pending-view.js` 或 API。
- 更新 `tests/static-shell.test.js`，验证 32 像素高度、居中布局、无小勾规则和颜色选中态。

## 验收

- 未选中标签文字在胶囊中水平、垂直居中。
- 胶囊高度在桌面与触屏设备上均为 32 像素。
- 选中后只改变背景、边框和文字颜色，不出现小勾或预留空白。
- 明暗主题下均可清楚辨认选中状态，文字对比度不低于 4.5:1。
- Tab、空格键、禁用态和读屏复选框语义保持不变。
- 相关 UI 测试、完整测试套件和 `git diff --check` 通过。
