# 单词标签与朗读控制修正设计

## 背景

当前词库添加单词表单只能选择已经加载的标签，不能在表单内创建标签；当账号尚无标签时，表单只显示一段不可操作的提示。文章朗读器则把持续保存的播放进度同时当成“上次暂停”位置，因此自动换句时也会移动并显示“上次暂停”标记。

本次改动同时补充两档朗读语速，并使当前句回听入口更容易理解。

## 目标

- 添加或编辑单词时，可以选择已有标签。
- 添加或编辑单词时，可以创建新标签；创建成功后自动选中。
- 正常播放和自动换句只更新恢复进度，不显示或移动“上次暂停”标记。
- 用户暂停、睡眠定时器暂停或页面中断时，记录并显示真实暂停位置。
- 语速提供 `0.5`、`0.75`、`1`、`1.25` 和 `1.5` 五档。
- “上一句”保留原意；“本句”改为带回放图标的“重听”。

## 单词标签交互

词库添加/编辑表单继续使用复选框展示已有标签，并在同一个标签区域增加标签名称输入框和“新建”按钮。提交新标签时调用现有 `POST /api/tags` 接口。

创建成功后：

1. 将返回的标签合并进当前页面标签集合，按标签 ID 去重；
2. 只重新渲染标签区域，不关闭添加/编辑表单；
3. 保留已经填写的单词、中文含义、重音和例句；
4. 自动勾选刚创建或接口返回的同名已有标签；
5. 保存单词时继续通过现有 `tagIds` 字段一次提交全部选中标签。

标签创建失败时，在标签区域显示错误并保留输入内容和当前选择。请求进行中禁用创建按钮，避免重复提交。表单卸载或切换页面后返回的旧请求不得修改新页面。

## 暂停标记与恢复进度

朗读器将两个概念明确分离：

- **恢复进度**：当前实际发声句及句内偏移。朗读中可按现有节流规则持续保存，用于页面恢复和跨设备继续。
- **暂停标记**：最近一次真实暂停的句子位置，只用于渲染“上次暂停”。

正常播放开始、音频时间更新和自然换句只更新恢复进度，不创建、移动或显示暂停标记。

以下情况更新暂停标记：

- 用户点击暂停；
- 睡眠定时器到期并暂停；
- 页面进入 `pagehide` 或阅读器卸载，需要保存中断位置；
- 浏览器播放器明确发布从播放到暂停的状态变化。

继续播放后移除页面上的“上次暂停”标记，但保留恢复进度。自然朗读完成、用户从头开始或重置文章进度时同时清除恢复进度和暂停标记。

服务端现有句子索引和偏移字段仍作为恢复进度使用，不新增数据库字段。暂停标记属于当前页面会话的展示状态；重新打开文章时，只有加载到的已保存断点才作为一次历史暂停位置显示。

## 语速控制

顶部语速滑块范围仍为 `0.5` 到 `1.5`，步长改为 `0.25`，因此可选择：

`0.5 / 0.75 / 1 / 1.25 / 1.5`

悬浮控制中的语速循环若存在，同样按这五档循环。语速输出继续显示为倍速，例如 `0.75×` 和 `1.25×`。

## 重听按钮

顶部工具栏和移动端悬浮控制保持两个不同操作：

- “上一句”：从当前实际发声句的前一句句首开始，并继续向后朗读；
- “重听”：从当前实际发声句句首开始，并继续向后朗读。

“上一句”使用向前回退/上一段图标，“重听”使用循环回放图标。按钮保留可见文字，不使用纯图标；同时提供完整 `aria-label`，分别为“重播上一句”和“重新朗读当前句”。第一句时“上一句”禁用，没有当前可回听句时“重听”禁用。

## 组件边界

- `public/words-view.js`：负责标签选择、新建标签的局部状态和单词表单提交。
- `public/reader-view.js`：负责区分恢复进度与暂停展示状态、渲染语速和回听按钮。
- 现有标签 API、TTS 播放器和恢复进度 API 保持接口兼容。
- CSS 只增加标签创建行和朗读按钮图标所需的局部样式，不改变整体布局。

## 错误处理

- 标签列表加载失败时，表单显示明确错误和重试入口，不再伪装成“没有标签”。
- 新建标签失败不影响单词表单中的其他字段。
- 暂停位置无效或超出句子范围时不渲染标记。
- 播放器属于其他文章或一次性点读时，不更新本文的暂停标记。

## 测试

使用现有 Node 测试和 JSDOM：

- 添加表单展示并可勾选已有标签；
- 在添加表单新建标签后自动选中，且保留其他字段；
- 标签创建失败和迟到响应不会破坏表单；
- 保存新单词时提交所有选中标签 ID；
- 播放开始和自动换句不会显示或移动“上次暂停”；
- 用户暂停、定时暂停和页面中断会在实际位置显示标记；
- 继续播放和自然完成会按规则移除标记；
- 语速控件具有五档值并能应用 `0.75` 与 `1.25`；
- 顶部和悬浮按钮显示“上一句”与“重听”、包含图标和正确的无障碍名称；
- 现有上一句与当前句回听行为保持不变。
