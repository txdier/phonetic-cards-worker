# 阅读器精确选择朗读起点与当前句跟随设计

## 背景

长文章阅读器已有顶部朗读工具栏、离屏悬浮朗读胶囊和跨设备朗读断点。当前仍有两个问题：

1. 用户通过“定位”跳到历史断点后，顶部工具栏已经离屏，但尚未开始朗读时缺少就近的“继续”入口。
2. 没有历史断点时，用户可能先手动翻到文章中部，再希望从自己指定的句子开始全文朗读。系统根据视口中点推测起点不够精确。
3. 全文朗读继续向下进行时，当前句可能移动到视口之外，用户无法同步看到正在朗读的内容。

## 目标

- 顶部朗读工具栏离开视口后，悬浮胶囊提供与当前状态匹配的朗读入口。
- 没有断点时，由用户明确选择全文朗读起点，不由系统猜测。
- 全文朗读过程中保证当前句处于安全可视区域，同时避免每句都引起不必要的页面移动。
- 保留现有单击句子朗读单句、文字长按选择、Azure TTS 优先和浏览器语音降级行为。

## 悬浮胶囊状态

悬浮胶囊仍以顶部朗读工具栏完全离开视口作为显示前提，并与词语、选区底部面板互斥。

| 阅读状态 | 可用断点 | 主要操作 |
| --- | --- | --- |
| 全文朗读中 | 任意 | 暂停 |
| 全文朗读已暂停 | 当前句 | 继续 |
| 空闲 | 有历史断点 | 继续 |
| 空闲 | 无历史断点 | 选择起点 |

倍率按钮继续按 `0.5× → 1× → 1.5×` 循环。空闲且存在历史断点时，“继续”从保存句子的开头开始。历史断点定位只移动和聚焦句子，不自动播放；定位完成后，离屏悬浮胶囊提供“继续”操作。

## 选择起点模式

空闲、无断点且顶部工具栏离屏时，悬浮胶囊显示“选择起点”。

点击后进入临时选择模式：

- 阅读正文增加选择模式状态类和简短提示。
- 每个句子获得轻量轮廓及可识别的悬停、触控和键盘焦点状态。
- 用户点击或通过键盘激活某一句后，退出选择模式，并从该句开头开始全文朗读。
- 选择模式下点击句内已高亮词也视为选择该句，不打开词语面板。
- 再次点击悬浮按钮、点击“取消”、按 `Escape` 或离开阅读页面时退出，不开始朗读。
- 选择模式不使用长按、双击或拖动，避免与手机浏览器原生文字选区冲突。
- 非选择模式下，现有单击句子朗读单句的行为保持不变。

选择模式只改变句子激活后的动作，不改变正文内容和句子索引。

## 当前朗读句自动跟随

收到全文朗读的 `speaking` 状态和当前句索引后，阅读器检查当前句的视口位置。

安全可视区域定义为：

- 上边界：视口顶部约 `15%`。
- 下边界：视口底部约 `78%`，为浏览器工具栏、悬浮胶囊和阅读余量留出空间。

处理规则：

- 当前句完整处于安全区域内时不滚动。
- 当前句超出上边界或接近、越过下边界时，根据句子视口位置计算滚动目标，将句子顶部移动到视口约 `32%` 处；不支持精确滚动时退回 `scrollIntoView({ block: "center" })`。
- 每个新当前句最多触发一次自动定位，重复状态通知不重复滚动。
- 用户暂停后不继续自动滚动；恢复朗读后从新的 `speaking` 状态继续检查。
- 历史断点加载和普通单句发音不触发自动跟随。
- 开启 `prefers-reduced-motion: reduce` 时使用即时滚动，否则使用平滑滚动。

该机制不更改阅读进度计算，也不会自动恢复历史滚动位置以外的新位置。

## 生命周期与无障碍

- 选择起点模式下，正文提供状态提示，句子继续支持 Enter 和空格键。
- 悬浮按钮的可访问名称随“暂停、继续、选择起点、取消选择”状态同步。
- 重新渲染或卸载阅读器时清理选择模式、观察器和临时状态。
- 打开词语或选区面板时隐藏胶囊；关闭后根据工具栏和朗读状态恢复。

## 测试

DOM 测试覆盖：

- 有历史断点、空闲且顶部工具栏离屏时显示“继续”，点击后从断点句开始。
- 无断点、空闲且顶部工具栏离屏时显示“选择起点”。
- 选择模式不会立即朗读；点击指定句后从准确索引开始全文朗读。
- Escape、再次点击和卸载会退出选择模式。
- 非选择模式下点击句子仍只朗读单句。
- 当前句处于安全区域时不滚动；越过上下边界时滚动到中部偏上。
- 重复的同一句状态不重复滚动，暂停和单句朗读不触发跟随。
- 减少动画设置使用即时滚动。

静态 CSS 测试覆盖选择模式轮廓、触控目标、焦点状态和减少动画规则。完整验证继续运行 `node --check public/reader-view.js`、目标测试及 `npm.cmd test`。

## 非目标

- 不加入拖动、双击、长按或句子旁常驻播放按钮。
- 不保存句内毫秒位置。
- 不改变 TTS 服务、朗读计数、滚动进度 API 或数据库结构。
- 不在加载文章时自动跳转到断点。
