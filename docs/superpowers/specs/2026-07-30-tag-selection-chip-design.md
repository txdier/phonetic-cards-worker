# 标签选择胶囊设计

## 背景

添加或编辑单词时，标签选项使用原生复选框。表单的通用
`.pc-form input` 规则会为所有输入元素设置整行宽度、内边距、背景和边框，
因此复选框被渲染成醒目的大块控件，标签名称还会落到下一行。

标签选项同时出现在词库添加/编辑表单和待整理收录表单，两处使用同一个
`.pc-tag-choice` 组件类。本次应统一修正，避免两个流程出现不同交互。

## 设计目标

- 将标签选项呈现为紧凑、易扫读的可选择胶囊。
- 未选中与已选中状态具有明确但不过度抢眼的视觉差异。
- 不只依赖颜色表达选中状态。
- 保留原生复选框的语义、表单提交行为和键盘操作。
- 明暗主题下均使用现有主题变量，不引入孤立的固定配色。
- 不改变标签创建、加载、重试及单词保存逻辑。

## 交互与视觉

### 未选中

- 使用圆角胶囊外形、主题面板背景和普通边框。
- 标签文字使用次级文字颜色。
- 整个胶囊均可点击，不要求用户精确点击小控件。

### 已选中

- 边框和文字切换为主题绿色。
- 背景增加低强度的主题绿色染色。
- 标签文字前显示一个小型勾选标记，确保选中状态不只靠颜色区分。
- 字重适度提高，但不改变胶囊尺寸，避免选择时布局跳动。

### 悬停、按下和焦点

- 鼠标悬停时加强边框和文字反馈。
- 按下时提供轻微的即时反馈，不产生明显位移。
- 原生复选框在视觉上隐藏，但仍保留在文档和 Tab 顺序中。
- 键盘聚焦时在胶囊外显示清晰焦点环；空格键继续切换复选框。
- 动效保持在 150–200 毫秒，并遵循现有的减少动态效果设置。

### 尺寸与排布

- 胶囊保持单行文字和完整点击区域，最小点击高度为 44 像素。
- 标签选项继续自动换行，缩小横向间距，使多标签排列更整齐。
- 长标签允许在可用空间内自然收缩，不造成页面横向溢出。

## 实现边界

- 主要改动位于 `public/styles.css`。
- 继续使用现有的 `label.pc-tag-choice > input[type="checkbox"] + 文本`
  结构，不替换为自定义按钮，也不改变 JavaScript 的标签 ID 收集逻辑。
- 使用 `:has(input:checked)` 和 `:has(input:focus-visible)` 驱动胶囊状态；
  项目现有样式已使用 `:has()`，因此不新增浏览器兼容性边界。
- 样式同时作用于 `public/words-view.js` 和 `public/pending-view.js`
  生成的标签选项。

## 无障碍

- 保留原生 `input[type="checkbox"]`，标签文字继续提供可访问名称。
- 已选中状态同时包含颜色变化和勾选标记。
- 焦点状态不能只依赖浏览器默认不可见轮廓。
- 文字与背景对比度应在明暗主题下保持可读。

## 测试与验收

- 静态样式测试确认标签复选框不再继承整行输入框外观。
- 静态样式测试确认未选中、选中和键盘焦点规则存在。
- 现有 DOM 测试继续验证复选框语义、标签选择和表单提交行为。
- 在浅色与深色主题下人工检查未选中、选中、悬停和键盘焦点状态。
- 在窄屏下确认标签能自然换行且页面无横向滚动。
- 运行相关定向测试、完整测试套件和 `git diff --check`。
