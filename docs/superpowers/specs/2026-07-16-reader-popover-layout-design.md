# 阅读浮窗与待整理列表布局设计

## 目标

解决两个界面问题：

- 待整理列表在 PC 端铺满可用宽度，单行内容过长且卡片空间利用率低。
- 阅读器中的划词、待整理词和词义详情浮窗结构不一致，关闭、标记和朗读操作的位置随状态变化。

本次只调整前端布局、交互组织和对应测试，不修改 API、数据库或待整理转换流程。

## 待整理列表

`.pc-pending-list` 在 PC 端使用 `max-width: 920px` 并水平居中，与应用导航、标题和统计列表的内容宽度保持一致。列表本身继续使用单列网格，各行卡片保持现有内容和操作。

在窄屏上列表宽度由父容器约束，自然缩至可用宽度，不设置固定最小宽度，也不产生横向滚动。

## 共享浮窗结构

阅读器中的三种状态使用同一套 DOM 骨架：

1. 右上角绝对定位的关闭按钮。
2. 词头行，包括当前词和紧邻词头的书签开关。
3. 可选的词汇元数据，仅词义详情态显示。
4. 分隔线。
5. 随状态变化的内容区。
6. 分隔线与固定底部工具栏，始终包含“发音”和“从本句开始全文朗读”。

三种状态仅替换内容区：

- 未标记：显示“标记为生词”主操作。
- 已标记：显示浅琥珀状态条、“加入记词本”主操作和低强调的“取消本篇标记”。左上角显示书签丝带。
- 词义详情：显示现有词元、词形、中文释义、例句和重音信息。当前词在本篇有标记时显示激活书签和丝带。

共享构建函数保留在 `public/reader-view.js` 中。当前只有阅读器使用此组件，暂不拆分为新模块，避免扩大重构范围。构建函数负责公共骨架和无障碍属性，各状态渲染函数只提供标题数据、内容节点和状态标志。

## 书签与状态切换

书签按钮具有开关语义：

- 未标记时使用描边图标，`aria-label` 为“标记生词”。
- 已标记时使用实心图标和浅琥珀背景，`aria-label` 为“取消本篇标记”，并通过可访问状态属性表达已选中。

未标记状态下，书签按钮和“标记为生词”主按钮调用同一现有标记 API。成功后更新阅读器本地文章数据并原地展示已标记状态，不要求用户重新点击该词。

已标记状态下，书签按钮和“取消本篇标记”调用同一现有删除 API。成功后刷新文章数据；失败时保留浮窗并展示现有行内错误，重新启用触发按钮。

“加入记词本”继续打开现有转换表单，冲突合并、新建卡片和提交中的互斥行为不变。

## 朗读与定位

打开浮窗时记录触发词所在的句子索引和浮窗朗读文本：

- “发音”朗读选中文字或被点击的词。
- “从本句开始全文朗读”调用现有 `speech.startAt(sentenceIndex)`，随后关闭当前浮窗。

PC 端浮窗根据选区或词按钮的视口矩形定位，限制在视口安全范围内。移动端使用文档流布局，避免固定浮层遮挡大部分正文或溢出屏幕。

## 关闭与焦点

以下操作关闭划词或词卡浮窗：

- 点击右上角关闭按钮。
- 按 `Escape`。
- 点击浮窗外的任意区域。

关闭后，如果原触发词仍在文档中，则将焦点还给它。划词触发没有可连接按钮时，仅清除选区。

转换表单沿用现有安全约束：空闲时可以取消或按 `Escape` 关闭；提交期间忽略关闭操作，避免隐藏仍在执行的转换请求。外部点击不会绕过该保护。

外部点击监听绑定在阅读器生命周期内，并在卸载时移除，避免切换页面后残留事件处理器。

## 视觉规则

浮窗沿用项目现有明暗主题变量，不引入外部字体或新的网络依赖：

- 琥珀色用于主操作、激活书签、丝带和状态提示。
- 普通工具按钮使用描边或幽灵样式，每个状态至多保留一个实心主按钮。
- 词头使用 Georgia、思源宋体思路的系统衬线回退字体栈；其余界面文字保持现有无衬线字体。
- 背景、边框和次要文字继续从 `--bg-panel`、`--line` 和 `--ink-dim` 取色，自动适配明暗主题。

## 错误处理与无障碍

- 浮窗继续使用对话框语义和描述当前词的 `aria-label`。
- 关闭、书签、发音和全文朗读均使用原生按钮并保留可见焦点样式。
- 浏览器不支持语音时，两个朗读入口均禁用。
- 网络错误使用现有阅读器行内错误区域，不用临时提示覆盖浮窗内容。
- 所有用户提供的词、释义和例句继续通过 `textContent` 写入 DOM。

## 测试

在现有 Node DOM 测试中覆盖：

- 三种状态拥有相同的关闭、词头和底部工具栏结构。
- 未标记成功后原地进入已标记状态并显示激活书签、丝带和状态条。
- 书签取消与文字取消调用相同的本篇删除端点。
- 词义详情保留现有数据，并显示固定朗读工具栏。
- 三种状态都能从所属句子开始全文朗读。
- 关闭按钮、`Escape` 和外部点击关闭浮窗并恢复焦点。
- 提交中的转换表单不会被外部点击或 `Escape` 关闭。
- 阅读器卸载后外部点击监听不再生效。
- 静态 CSS 测试确认待整理列表使用 `max-width: 920px`、水平居中，并保留移动端自适应规则。

最后运行完整测试套件，确认文章阅读、待整理转换、语音和进度行为没有回归。
