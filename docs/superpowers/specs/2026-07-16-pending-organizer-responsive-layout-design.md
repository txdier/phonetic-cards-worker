# 待整理页响应式布局设计

日期：2026-07-16

## 1. 背景与目标

当前待整理页在桌面端使用约 920px 宽的单列大卡片，卡片内部留白过多，宽屏空间利用率低；移动端每个词条的两个操作按钮分行占据较大高度，连续整理时滚动距离过长。

本次调整只重做待整理词条列表及其操作区，不改变页面导航、颜色体系、数据结构、接口、转换表单或删除确认流程。

目标如下：

- 保留现有米白背景、橙色主操作和青绿色选中态；
- 桌面宽屏每行展示三个词条；
- 中等宽度每行展示两个词条；
- 手机保持单列，避免短语和触控区域相互挤压；
- 缩短按钮文案并改为上下排列，让词条获得更多横向空间；
- 词条固定使用 16px 字号；文本宽度未超过内容区时保持单行，超过时完整换行，不缩小字号，也不使用省略号截断。

## 2. 选定方案

采用“三列词条账本”布局。列表作为一个连续的整理表面，通过细分隔线划分词条，不再为每个词条使用大尺寸独立卡片。

每个词条单元由两部分组成：

1. 左侧内容区：英文词条或短语，下面显示“单词/短语”和来源数量；
2. 右侧操作区：两个上下排列的按钮，上方为“＋ 收录”，下方为“× 移除”。

“收录”继续触发现有加入记词本流程；“移除”继续触发现有全局取消标记确认流程。两项操作始终直接可见，不增加菜单、抽屉或中间确认层。

## 3. 响应式规则

### 3.1 宽屏桌面

- 视口宽度不小于 1100px 时使用三列；
- 待整理内容区域最大宽度扩大到 1200px，并保留与站点其他页面一致的外侧留白；
- 每个单元内部为“内容区 + 固定宽度操作区”；
- 同一行单元高度由该行最高内容自然决定，不固定文本高度。

### 3.2 中等宽度与平板

- 视口宽度为 700px 至 1099px 时使用两列；
- 操作区仍保持上下排列；
- 不改变信息与操作顺序。

### 3.3 手机

- 视口宽度小于 700px 时使用单列；
- 词条与元信息在左，竖排操作在右；
- 两个按钮的触控高度均不小于 44px，按钮之间至少保留 8px 间距；
- 页面不得出现水平滚动；
- 长短语自然换行，操作区不被挤出屏幕。

## 4. 视觉规格

### 4.1 字体与文本

- 英文词条在桌面和手机均使用 16px；
- 词条保持现有页面字体与粗体层级；
- 元信息弱化显示，但保持可读对比度；
- 词条允许在必要时换行，使用 `overflow-wrap` 处理没有自然断点的异常长文本；
- 不使用单行截断或省略号，因为用户需要看到完整的待整理内容。

### 4.2 表面与分隔

- 列表保留轻微的白色或半透明白色表面；
- 使用现有暖色边框色绘制水平和垂直分隔线；
- 不为每个词条增加独立阴影；
- 外层列表可保留轻微圆角，但内部单元不重复圆角。

### 4.3 操作按钮

- “＋ 收录”为橙色主按钮；
- “× 移除”为白底、暖色边框、红色文字的次级危险按钮；
- 两个按钮宽度一致并上下排列；
- 桌面按钮高度为 32px，手机按钮高度为 44px；
- 图标使用 SVG 或 CSS 图形，不使用 emoji；
- 可访问名称包含具体词条，例如“将 keeps 收录到记词本”和“移除 keeps 的全部标记”。

## 5. 状态与交互

- 加载态、空状态和页级错误继续沿用现有行为；
- 转换或删除请求进行中时，继续禁用所有相关行操作，避免并发修改；
- 禁用态必须同时具有原生 `disabled` 语义与清晰的视觉弱化；
- “移除”仍打开现有破坏性确认对话框，确认后删除全部来源；
- “收录”仍打开现有转换表单，成功后从列表移除该词条；
- 键盘焦点顺序按视觉顺序遍历：词条一的收录、移除，再进入下一词条；
- 保留清晰的键盘焦点轮廓。

## 6. 组件与代码边界

主要修改范围：

- `public/pending-view.js`：调整两个按钮的可见文案、图标结构和可访问名称；
- `public/styles.css`：重写待整理列表、词条单元、操作区和响应式断点样式；
- `tests/reader-pending-dom.test.js`：更新按钮文案相关断言，并补充结构与可访问名称测试；
- 必要时更新其他依赖可见文案的界面测试，但不改动 API 测试。

转换表单、冲突合并、全局删除逻辑及 API 路径保持不变。

## 7. 测试与验收

### 7.1 自动化测试

- 每个词条仍渲染一个收录按钮和一个移除按钮；
- 两个按钮保留原有 `data-action`，现有事件委托继续工作；
- 按钮具有包含词条内容的可访问名称；
- 收录、取消、冲突合并、请求中禁用和清理监听器的既有测试继续通过；
- 空状态和错误状态不回归。

### 7.2 响应式验收

- 1440px 与 1100px：每行三项；
- 1024px 与 768px：每行两项；
- 390px 与 375px：单列，无水平滚动；
- 词条在 16px 字号下只在文本宽度超过内容区时换行；
- 超长短语完整显示并自然增加单元高度；
- 手机按钮触控高度不小于 44px，间距不小于 8px。

### 7.3 视觉验收

- 页面继续呈现现有暖色纸张风格；
- 宽屏空间利用率明显高于原单列布局；
- 每个词条不再出现大面积无效留白；
- “收录”与“移除”的主次关系清楚，且无需额外操作层才能触发。

## 8. 非目标

- 不重做导航、页面标题或转换表单；
- 不增加批量操作、筛选、排序或搜索；
- 不改变待整理数据模型和 API；
- 不引入新的前端框架、图标库或设计系统；
- 不改变删除确认语义。
