# 词库分页状态与首页尾页导航设计

## 目标

增强词库页面的分页信息与快速导航，让用户能看到当前页和总页数，并可从非首页快速返回首页、从多页列表的非尾页快速前往尾页。

## 范围

本次只修改词库页面的分页渲染、交互和相关测试。词库 API 已返回 `total`、`page` 和 `pageSize`，无需修改后端接口或数据结构。

## 交互设计

分页控件按以下顺序排列：

`首页　上一页　第 N / 共 M 页　下一页　尾页`

- 总页数按 `Math.max(1, Math.ceil(total / pageSize))` 计算，空词库也显示为共 1 页。
- “首页”仅在当前页大于 1 时显示，点击后加载第 1 页。
- “尾页”仅在总页数大于 2 且当前页小于总页数时显示，点击后加载最后一页。
- “上一页”和“下一页”继续保留；首页禁用“上一页”，尾页禁用“下一页”。
- 页码状态文案由“第 N 页”改为“第 N / 共 M 页”。

## 实现设计

在 `public/words-view.js` 的词库视图内部，根据已有的 `total` 与 `pageSize` 计算总页数。分页 HTML 根据当前页和总页数条件渲染首页、尾页按钮。点击事件增加 `page-first` 与 `page-last` 两个动作，更新 `currentPage` 后复用现有 `loadLibrary()` 请求和重绘流程。

保持现有分页样式，仅在小屏幕需要时允许分页容器换行，避免新增按钮挤出视口。

## 测试设计

在现有词库 DOM 测试中覆盖：

- 首页显示当前页与总页数，不显示首页按钮；总页数超过两页且未到尾页时显示尾页按钮。
- 中间页显示首页和尾页按钮。
- 尾页显示首页按钮，不显示尾页按钮，并禁用下一页。
- 点击首页请求第 1 页，点击尾页请求计算出的最后一页。
- 总页数不超过两页时不显示尾页按钮。

测试先失败，再以最小生产代码使其通过，最后运行完整测试套件。
