# 手机端悬浮朗读控制条修复设计

## 背景与根因

文章阅读器顶部朗读栏离开视口后，会显示悬浮朗读控制条。此前加入“上一句”“重听”和“定时”时，原有的悬浮语速循环按钮被删除，导致用户无法在阅读过程中就近调整语速。

当前悬浮条使用四列单行网格。按钮同时带有图标或文字、强制不换行、保留至少 44px 的触控宽度，并叠加列间距和容器内边距。在手机窄屏上，这些约束会使控制条内容超出可用宽度，造成图标或按钮显示不完整。

## 目标

- 恢复悬浮控制条中的语速调整入口。
- 悬浮控制条在手机屏幕上始终保持单行。
- 所有控制在 320px、375px 和手机横屏宽度下完整显示，不产生横向滚动或裁切。
- 保留至少 44×44px 的触控区域、键盘焦点样式和屏幕阅读器名称。
- 不改变顶部朗读栏、朗读状态机、定时器或完成统计的既有行为。

## 方案

悬浮控制条固定包含五个控制，顺序为：

1. 上一句；
2. 重听当前句；
3. 播放、暂停、继续或选择起点；
4. 定时；
5. 语速。

在手机断点下，前四项只显示 SVG 图标，不显示可见文字。语速按钮显示当前倍率，例如 `1×`，因为倍率本身是用户需要直接读取的状态。每个图标按钮继续使用完整的中文 `aria-label`，动态播放状态、定时剩余时间和当前倍率也同步更新无障碍名称。

较宽屏幕继续使用现有图标加短文字的表达；恢复的语速按钮在所有宽度显示当前倍率。

## 布局

悬浮条改为五列网格。手机断点下使用五个等宽列，每列允许收缩到容器分配宽度，但按钮的触控区域不得小于 44×44px。缩小列间距和胶囊内边距，使五个触控目标在 320px 视口减去安全边距后仍完整容纳。

控制条继续：

- 固定在视口底部并考虑 `safe-area-inset-bottom`；
- 为正文预留底部空间；
- 与词语、选区、阅读设置和定时面板互斥；
- 不使用横向滚动，不换行，不隐藏任何操作。

## 交互与状态同步

语速按钮复用原有的 `speech-rate-cycle` 行为，按以下顺序循环：

`0.5× → 0.75× → 1× → 1.25× → 1.5× → 0.5×`

点击后调用当前音频控制器的语速设置接口，并同步：

- 顶部语速滑块；
- 顶部倍率输出；
- 悬浮语速按钮文字；
- 悬浮语速按钮的 `aria-label`。

播放按钮根据现有状态继续切换播放、暂停、继续、选择起点和取消选择。手机端只替换其可见内容为对应状态图标，不改变事件动作或状态判断。

定时按钮未启用时显示定时图标；启用后可显示剩余时间。剩余时间仍放在同一个等宽控制位内，并使用等宽数字，避免倒计时造成布局抖动。

## 图标与无障碍

图标沿用项目现有的线性 SVG 风格，并补齐播放、暂停、定时等缺少的状态图标。图标仅作视觉表达，按钮的语义来自原生 `button`、`aria-label`、`disabled` 和现有 `aria-expanded`。

键盘焦点、按下反馈、禁用态和深浅主题颜色继续使用现有主题变量。手机端隐藏的文字不得成为唯一的无障碍名称。

## 测试与验收

DOM 测试覆盖：

- 悬浮条按既定顺序渲染五个操作；
- 语速按钮显示当前倍率并按既定序列循环；
- 调速后顶部滑块、顶部输出和悬浮按钮保持同步；
- 播放状态改变时，手机图标对应当前动作且 `aria-label` 正确；
- 不支持语音时，五个朗读控制按既有规则禁用。

样式测试覆盖：

- 默认悬浮条为五列单行网格；
- 手机断点隐藏按钮文字但保留图标和倍率；
- 每个按钮至少具有 44px 高度和宽度；
- 320px、375px 和横屏布局无横向滚动、裁切或换行；
- 安全区和正文底部预留仍然有效。

手动验收在真实或模拟手机视口中检查：所有图标完整可见、按钮易于点击、语速可以循环调整、倒计时不会撑破布局，深浅主题与横屏方向均可用。

## 非目标

- 不重新设计顶部朗读栏。
- 不改变朗读、回听、断点、定时和完成统计规则。
- 不增加更多语速档位或弹出式语速面板。
- 不通过缩小触控目标、横向滚动或隐藏操作来换取空间。
